# Remember a stated preference

Use this when the user explicitly describes how they want future work handled. Find the user's actual words and the task where they apply. Record the source card and scope. A suggestion from an agent carries the agent's authorship.

With the user's authorization, add the preference to the relevant editable role. If its scope is unclear, leave the observation on the current card. On a later comparable task, check the result against what the user asked for.
