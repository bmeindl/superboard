# Learn from one correction

Run this on a completed card when a correction would be worth catching earlier. Retrieve the initial draft, the checker's return and the accepted result.

1. Quote the specific claim that changed and cite the source that settled it.
2. Check whether the current role instructions already address the miss. If they do, look for a missing input or a skipped step before adding another rule.
3. If the user authorized a method change, make the smallest useful edit in the responsible role's ROLE.md. Otherwise show the proposed wording and its destination.
4. Record the original example, the change and a new trial on the card. Run the fresh example separately and follow crew/rituals/effect-check.md.

For the release example, check whether the writer can identify the audience and availability of each feature before sending the first draft.
