Threads, sessions and cache

Keep the history; cut the session when the outcome changes.

▶ Agent runs the selected CLI in auto mode. It can act with the access and MCP/provider configuration that CLI inherits.

The same card normally continues its provider session. A warm prompt cache can reduce repeated processing; a cold cache loses no board data.

✂ New thread keeps the written history but makes the next run start with a fresh session. Use it for a new outcome or when old context has become baggage.

When the agent needs an interactive login or terminal-only action, ask it for the exact handoff commands. Superboard does not add a second approval system around your agent CLI.
