00 · FIRST: WHAT THE COCKPIT IS

Next to TO-DOS there is a second tab, COCKPIT. It holds buttons, and a button is nothing mysterious: a saved sentence to the agent with a name on it.

Shortcuts — things you'd otherwise type again and again: "clean up the board", "digest my inbox". Press, the run starts, the result lands as a card.

Routines — the same buttons on a schedule: every morning, every Friday, when you open the tab. Off Duty and night rest pause them.

It starts with a single shipped button — ⬆ Check for updates — and fills up because you ask for more buttons, which is what every example below does.
