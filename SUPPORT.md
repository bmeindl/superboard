# Support

Superboard is a personal working tool, shared as-is. There is no support, SLA,
or roadmap commitment, and no guarantee that an issue or pull request receives
a response.

Reproducible bugs and narrowly scoped improvement proposals are welcome as
GitHub Issues. Please search existing issues first and include the Superboard
version, operating system, start command, and the smallest reproduction you can
provide. Forks are welcome — that is what the MIT license is for.
